# Datos, confidencialidad y condiciones de uso

La fuente es ENEMDU 2025 (INEC, Ecuador). No se distribuyen microdatos, archivos de variables personales, índices de prueba por registro, predicciones individuales, artefactos de modelos ni la copia de los datos analizados.

Para reconstruir la ejecución histórica, consulte el acceso oficial al INEC y las condiciones de uso vigentes. El ZIP histórico de investigación es un insumo privado que debe mantenerse fuera de GitHub. Los valores agregados de las matrices de confusión y las métricas pueden consultarse en `evidencias/`.

El original contiene registros de una encuesta con posiciones persona–hogar repetidas. No interpretarlas automáticamente como personas únicas ni usar el split aleatorio como validación longitudinal independiente.
